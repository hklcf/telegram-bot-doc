# getForumTopicIconStickers

> Part of the [Telegram Bot API](../../api.md). Canonical location: [getForumTopicIconStickers](../../api.md#getforumtopiciconstickers).

Use this method to get custom emoji stickers, which can be used as a forum topic icon by any user. Requires no parameters. Returns an Array of [Sticker](../types/sticker.md) objects.
