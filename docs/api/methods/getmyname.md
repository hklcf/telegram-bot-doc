# getMyName

> Part of the [Telegram Bot API](../../api.md). Canonical location: [getMyName](../../api.md#getmyname).

Use this method to get the current bot name for the given user language. Returns [BotName](../types/botname.md) on success.

|Parameter|Type|Required|Description|
|-----------|
|language_code|String|Optional|A two-letter ISO 639-1 language code or an empty string|
