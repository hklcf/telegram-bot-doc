# getBusinessConnection

> Part of the [Telegram Bot API](../../api.md). Canonical location: [getBusinessConnection](../../api.md#getbusinessconnection).

Use this method to get information about the connection of the bot with a business account. Returns a [BusinessConnection](../types/businessconnection.md) object on success.

|Parameter|Type|Required|Description|
|-----------|
|business_connection_id|String|Yes|Unique identifier of the business connection|
