# getStickerSet

> Part of the [Telegram Bot API](../../api.md). Canonical location: [getStickerSet](../../api.md#getstickerset).

Use this method to get a sticker set. On success, a [StickerSet](../types/stickerset.md) object is returned.

|Parameter|Type|Required|Description|
|-----------|
|name|String|Yes|Name of the sticker set|
