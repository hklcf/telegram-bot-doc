# getUniqueGift

> Part of the [Telegram Bot API](../../api.md). Canonical location: [getUniqueGift](../../api.md#getuniquegift).

Use this method to get information about a unique gift by its name. Returns a [UniqueGift](../types/uniquegift.md) object on success.

|Parameter|Type|Required|Description|
|-----------|
|name|String|Yes|Unique name of the gift|
