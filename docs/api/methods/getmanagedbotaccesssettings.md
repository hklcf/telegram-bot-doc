# getManagedBotAccessSettings

> Part of the [Telegram Bot API](../../api.md). Canonical location: [getManagedBotAccessSettings](../../api.md#getmanagedbotaccesssettings).

Use this method to get the access settings of a managed bot. Returns a [BotAccessSettings](../types/botaccesssettings.md) object on success.

|Parameter|Type|Required|Description|
|-----------|
|user_id|Integer|Yes|User identifier of the managed bot whose access settings will be returned|
