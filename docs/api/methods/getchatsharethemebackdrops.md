# getChatShareThemeBackdrops

> Part of the [Telegram Bot API](../../api.md). Canonical location: [getChatShareThemeBackdrops](../../api.md#getchatsharethemebackdrops).

Use this method to get the list of backdrops, which can be used as the background of a theme of the screen for sharing a link to a user or a chat. Requires no parameters. Returns a [ChatShareThemeBackdrops](../types/chatsharethemebackdrops.md) object.
