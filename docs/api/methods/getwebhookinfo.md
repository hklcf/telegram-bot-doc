# getWebhookInfo

> Part of the [Telegram Bot API](../../api.md). Canonical location: [getWebhookInfo](../../api.md#getwebhookinfo).

Use this method to get current webhook status. Requires no parameters. On success, returns a [WebhookInfo](../types/webhookinfo.md) object. If the bot is using [getUpdates](./getupdates.md), will return an object with the *url* field empty.
