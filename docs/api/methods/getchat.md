# getChat

> Part of the [Telegram Bot API](../../api.md). Canonical location: [getChat](../../api.md#getchat).

Use this method to get up-to-date information about the chat. Returns a [ChatFullInfo](../types/chatfullinfo.md) object on success.

|Parameter|Type|Required|Description|
|-----------|
|chat_id|Integer or String|Yes|Unique identifier for the target chat or username of the target supergroup or channel in the format `@username`|
