> Part of the [Telegram Bot API](../../api.md). Canonical location: [InputPaidMedia](../../api.md#inputpaidmedia).

* [InputPaidMediaLivePhoto](./inputpaidmedialivephoto.md)
* [InputPaidMediaPhoto](./inputpaidmediaphoto.md)
