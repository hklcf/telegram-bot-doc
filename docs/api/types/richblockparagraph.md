# RichBlockParagraph

> Part of the [Telegram Bot API](../../api.md). Canonical location: [RichBlockParagraph](../../api.md#richblockparagraph).

A text paragraph, corresponding to the HTML tag `<p>`.

|Field|Type|Description|
|-----------|
|type|String|Type of the block, always "paragraph"|
|text|[RichText](./richtext.md)|Text of the block|
