# InputRichMessageContent

> Part of the [Telegram Bot API](../../api.md). Canonical location: [InputRichMessageContent](../../api.md#inputrichmessagecontent).

Represents the [content](./inputmessagecontent.md) of a rich message to be sent as the result of an inline query.

|Field|Type|Description|
|-----------|
|rich_message|[InputRichMessage](./inputrichmessage.md)|The message to be sent. Only previously uploaded files may be used in the message.|
