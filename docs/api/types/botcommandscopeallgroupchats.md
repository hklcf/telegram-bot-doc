# BotCommandScopeAllGroupChats

> Part of the [Telegram Bot API](../../api.md). Canonical location: [BotCommandScopeAllGroupChats](../../api.md#botcommandscopeallgroupchats).

Represents the [scope](./botcommandscope.md) of bot commands, covering all group and supergroup chats.

|Field|Type|Description|
|-----------|
|type|String|Scope type, must be *all_group_chats*|
