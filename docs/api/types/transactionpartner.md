# TransactionPartner

> Part of the [Telegram Bot API](../../api.md). Canonical location: [TransactionPartner](../../api.md#transactionpartner).

This object describes the source of a transaction, or its recipient for outgoing transactions. Currently, it can be one of

* [TransactionPartnerUser](./transactionpartneruser.md)
* [TransactionPartnerChat](./transactionpartnerchat.md)
* [TransactionPartnerAffiliateProgram](./transactionpartneraffiliateprogram.md)
* [TransactionPartnerFragment](./transactionpartnerfragment.md)
* [TransactionPartnerTelegramAds](./transactionpartnertelegramads.md)
* [TransactionPartnerTelegramApi](./transactionpartnertelegramapi.md)
* [TransactionPartnerOther](./transactionpartnerother.md)
