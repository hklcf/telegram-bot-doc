# BotCommandScopeAllChatAdministrators

> Part of the [Telegram Bot API](../../api.md). Canonical location: [BotCommandScopeAllChatAdministrators](../../api.md#botcommandscopeallchatadministrators).

Represents the [scope](./botcommandscope.md) of bot commands, covering all group and supergroup chat administrators.

|Field|Type|Description|
|-----------|
|type|String|Scope type, must be *all_chat_administrators*|
