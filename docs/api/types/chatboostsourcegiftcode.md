# ChatBoostSourceGiftCode

> Part of the [Telegram Bot API](../../api.md). Canonical location: [ChatBoostSourceGiftCode](../../api.md#chatboostsourcegiftcode).

The boost was obtained by the creation of Telegram Premium gift codes to boost a chat. Each such code boosts the chat 4 times for the duration of the corresponding Telegram Premium subscription.

|Field|Type|Description|
|-----------|
|source|String|Source of the boost, always "gift_code"|
|user|[User](./user.md)|User for which the gift code was created|
