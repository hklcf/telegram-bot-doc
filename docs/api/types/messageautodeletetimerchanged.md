# MessageAutoDeleteTimerChanged

> Part of the [Telegram Bot API](../../api.md). Canonical location: [MessageAutoDeleteTimerChanged](../../api.md#messageautodeletetimerchanged).

This object represents a service message about a change in auto-delete timer settings.

|Field|Type|Description|
|-----------|
|message_auto_delete_time|Integer|New auto-delete time for messages in the chat; in seconds|
