# InputRichBlockMathematicalExpression

> Part of the [Telegram Bot API](../../api.md). Canonical location: [InputRichBlockMathematicalExpression](../../api.md#inputrichblockmathematicalexpression).

A block with a mathematical expression in LaTeX format, corresponding to the custom HTML tag `<tg-math-block>`.

|Field|Type|Description|
|-----------|
|type|String|Type of the block, always "mathematical_expression"|
|expression|String|The mathematical expression in LaTeX format|
