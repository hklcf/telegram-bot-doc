# StoryAreaTypeLink

> Part of the [Telegram Bot API](../../api.md). Canonical location: [StoryAreaTypeLink](../../api.md#storyareatypelink).

Describes a story area pointing to an HTTP or tg:// link. Currently, a story can have up to 3 link areas.

|Field|Type|Description|
|-----------|
|type|String|Type of the area, always "link"|
|url|String|HTTP or tg:// URL to be opened when the area is clicked|
