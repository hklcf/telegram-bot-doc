# BusinessOpeningHours

> Part of the [Telegram Bot API](../../api.md). Canonical location: [BusinessOpeningHours](../../api.md#businessopeninghours).

Describes the opening hours of a business.

|Field|Type|Description|
|-----------|
|time_zone_name|String|Unique name of the time zone for which the opening hours are defined|
|opening_hours|Array of [BusinessOpeningHoursInterval](./businessopeninghoursinterval.md)|List of time intervals describing business opening hours|
