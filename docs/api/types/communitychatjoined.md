# CommunityChatJoined

> Part of the [Telegram Bot API](../../api.md). Canonical location: [CommunityChatJoined](../../api.md#communitychatjoined).

Describes a service message about a chat being joined by a user from a community.

|Field|Type|Description|
|-----------|
|community|[Community](./community.md)|The community from which the chat was joined|
