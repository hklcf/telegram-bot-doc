# MaybeInaccessibleMessage

> Part of the [Telegram Bot API](../../api.md). Canonical location: [MaybeInaccessibleMessage](../../api.md#maybeinaccessiblemessage).

This object describes a message that can be inaccessible to the bot. It can be one of

* [Message](./message.md)
* [InaccessibleMessage](./inaccessiblemessage.md)
