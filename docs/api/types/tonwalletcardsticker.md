# TonWalletCardSticker

> Part of the [Telegram Bot API](../../api.md). Canonical location: [TonWalletCardSticker](../../api.md#tonwalletcardsticker).

This object describes a sticker on a TON wallet card.

|Field|Type|Description|
|-----------|
|position|[AreaPosition](./areaposition.md)|Position of the sticker on the card|
|nft|[TonNft](./tonnft.md)|The NFT shown as the sticker|
