# RichBlockAudio

> Part of the [Telegram Bot API](../../api.md). Canonical location: [RichBlockAudio](../../api.md#richblockaudio).

A block with a music file, corresponding to the HTML tag `<audio>`.

|Field|Type|Description|
|-----------|
|type|String|Type of the block, always "audio"|
|audio|[Audio](./audio.md)|The audio|
|caption|[RichBlockCaption](./richblockcaption.md)|*Optional*. Caption of the block|
