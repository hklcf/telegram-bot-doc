# RichTextEmailAddress

> Part of the [Telegram Bot API](../../api.md). Canonical location: [RichTextEmailAddress](../../api.md#richtextemailaddress).

A text with an email address.

|Field|Type|Description|
|-----------|
|type|String|Type of the rich text, always "email_address"|
|text|[RichText](./richtext.md)|The text|
|email_address|String|The email address|
