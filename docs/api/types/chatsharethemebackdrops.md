# ChatShareThemeBackdrops

> Part of the [Telegram Bot API](../../api.md). Canonical location: [ChatShareThemeBackdrops](../../api.md#chatsharethemebackdrops).

This object contains a list of backdrops, which can be used as the background of a theme of the screen for sharing a link to a user or a chat.

|Field|Type|Description|
|-----------|
|backdrops|Array of [ChatShareThemeBackdrop](./chatsharethemebackdrop.md)|The list of backdrops|
