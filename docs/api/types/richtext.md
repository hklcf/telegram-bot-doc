# RichText

> Part of the [Telegram Bot API](../../api.md). Canonical location: [RichText](../../api.md#richtext).

This object represents a rich formatted text. Currently, it can be either a String for plain text, an Array of [RichText](./richtext.md), or any of the following types:

* [RichTextBold](./richtextbold.md)
* [RichTextItalic](./richtextitalic.md)
* [RichTextUnderline](./richtextunderline.md)
* [RichTextStrikethrough](./richtextstrikethrough.md)
* [RichTextSpoiler](./richtextspoiler.md)
* [RichTextDateTime](./richtextdatetime.md)
* [RichTextTextMention](./richtexttextmention.md)
* [RichTextSubscript](./richtextsubscript.md)
* [RichTextSuperscript](./richtextsuperscript.md)
* [RichTextMarked](./richtextmarked.md)
* [RichTextCode](./richtextcode.md)
* [RichTextCustomEmoji](./richtextcustomemoji.md)
* [RichTextMathematicalExpression](./richtextmathematicalexpression.md)
* [RichTextUrl](./richtexturl.md)
* [RichTextEmailAddress](./richtextemailaddress.md)
* [RichTextPhoneNumber](./richtextphonenumber.md)
* [RichTextBankCardNumber](./richtextbankcardnumber.md)
* [RichTextTonAddress](./richtexttonaddress.md)
* [RichTextMention](./richtextmention.md)
* [RichTextHashtag](./richtexthashtag.md)
* [RichTextCashtag](./richtextcashtag.md)
* [RichTextBotCommand](./richtextbotcommand.md)
* [RichTextButton](./richtextbutton.md)
* [RichTextAnchor](./richtextanchor.md)
* [RichTextAnchorLink](./richtextanchorlink.md)
* [RichTextReference](./richtextreference.md)
* [RichTextReferenceLink](./richtextreferencelink.md)
