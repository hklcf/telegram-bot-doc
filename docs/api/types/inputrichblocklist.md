# InputRichBlockList

> Part of the [Telegram Bot API](../../api.md). Canonical location: [InputRichBlockList](../../api.md#inputrichblocklist).

A list of blocks, corresponding to the HTML tag `<ul>` or `<ol>` with multiple nested tags `<li>`.

|Field|Type|Description|
|-----------|
|type|String|Type of the block, always "list"|
|items|Array of [InputRichBlockListItem](./inputrichblocklistitem.md)|Items of the list|
