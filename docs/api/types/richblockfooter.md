# RichBlockFooter

> Part of the [Telegram Bot API](../../api.md). Canonical location: [RichBlockFooter](../../api.md#richblockfooter).

A footer, corresponding to the HTML tag `<footer>`.

|Field|Type|Description|
|-----------|
|type|String|Type of the block, always "footer"|
|text|[RichText](./richtext.md)|Text of the block|
