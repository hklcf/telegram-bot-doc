# ReactionTypeCustomEmoji

> Part of the [Telegram Bot API](../../api.md). Canonical location: [ReactionTypeCustomEmoji](../../api.md#reactiontypecustomemoji).

The reaction is based on a custom emoji.

|Field|Type|Description|
|-----------|
|type|String|Type of the reaction, always "custom_emoji"|
|custom_emoji_id|String|Custom emoji identifier|
