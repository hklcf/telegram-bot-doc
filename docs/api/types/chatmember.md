# ChatMember

> Part of the [Telegram Bot API](../../api.md). Canonical location: [ChatMember](../../api.md#chatmember).

This object contains information about one member of a chat. Currently, the following 6 types of chat members are supported:

* [ChatMemberOwner](./chatmemberowner.md)
* [ChatMemberAdministrator](./chatmemberadministrator.md)
* [ChatMemberMember](./chatmembermember.md)
* [ChatMemberRestricted](./chatmemberrestricted.md)
* [ChatMemberLeft](./chatmemberleft.md)
* [ChatMemberBanned](./chatmemberbanned.md)
