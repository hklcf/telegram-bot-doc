# UniqueGiftSymbol

> Part of the [Telegram Bot API](../../api.md). Canonical location: [UniqueGiftSymbol](../../api.md#uniquegiftsymbol).

This object describes the symbol shown on the pattern of a unique gift.

|Field|Type|Description|
|-----------|
|name|String|Name of the symbol|
|sticker|[Sticker](./sticker.md)|The sticker that represents the unique gift|
|rarity_per_mille|Integer|The number of unique gifts that receive this model for every 1000 gifts upgraded|
