# PaidMediaPurchased

> Part of the [Telegram Bot API](../../api.md). Canonical location: [PaidMediaPurchased](../../api.md#paidmediapurchased).

This object contains information about a paid media purchase.

|Field|Type|Description|
|-----------|
|from|[User](./user.md)|User who purchased the media|
|paid_media_payload|String|Bot-specified paid media payload|
