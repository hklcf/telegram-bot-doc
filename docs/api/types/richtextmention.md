# RichTextMention

> Part of the [Telegram Bot API](../../api.md). Canonical location: [RichTextMention](../../api.md#richtextmention).

A mention by a username.

|Field|Type|Description|
|-----------|
|type|String|Type of the rich text, always "mention"|
|text|[RichText](./richtext.md)|The text|
|username|String|The username|
