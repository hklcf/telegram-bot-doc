# UserProfileAudios

> Part of the [Telegram Bot API](../../api.md). Canonical location: [UserProfileAudios](../../api.md#userprofileaudios).

This object represents the audios displayed on a user's profile.

|Field|Type|Description|
|-----------|
|total_count|Integer|Total number of profile audios for the target user|
|audios|Array of [Audio](./audio.md)|Requested profile audios|
