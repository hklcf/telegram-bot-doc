# InputRichBlockSlideshow

> Part of the [Telegram Bot API](../../api.md). Canonical location: [InputRichBlockSlideshow](../../api.md#inputrichblockslideshow).

A slideshow, corresponding to the custom HTML tag `<tg-slideshow>`.

|Field|Type|Description|
|-----------|
|type|String|Type of the block, always "slideshow"|
|blocks|Array of [InputRichBlock](./inputrichblock.md)|Elements of the slideshow|
|caption|[RichBlockCaption](./richblockcaption.md)|*Optional*. Caption of the block|
