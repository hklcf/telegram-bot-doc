# ChatBoostUpdated

> Part of the [Telegram Bot API](../../api.md). Canonical location: [ChatBoostUpdated](../../api.md#chatboostupdated).

This object represents a boost added to a chat or changed.

|Field|Type|Description|
|-----------|
|chat|[Chat](./chat.md)|Chat which was boosted|
|boost|[ChatBoost](./chatboost.md)|Information about the chat boost|
