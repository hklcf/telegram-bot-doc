# RichBlockList

> Part of the [Telegram Bot API](../../api.md). Canonical location: [RichBlockList](../../api.md#richblocklist).

A list of blocks, corresponding to the HTML tag `<ul>` or `<ol>` with multiple nested tags `<li>`.

|Field|Type|Description|
|-----------|
|type|String|Type of the block, always "list"|
|items|Array of [RichBlockListItem](./richblocklistitem.md)|Items of the list|
