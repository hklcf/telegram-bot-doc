# PaidMediaInfo

> Part of the [Telegram Bot API](../../api.md). Canonical location: [PaidMediaInfo](../../api.md#paidmediainfo).

Describes the paid media added to a message.

|Field|Type|Description|
|-----------|
|star_count|Integer|The number of Telegram Stars that must be paid to buy access to the media|
|paid_media|Array of [PaidMedia](./paidmedia.md)|Information about the paid media|
