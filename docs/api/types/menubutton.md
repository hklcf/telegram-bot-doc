# MenuButton

> Part of the [Telegram Bot API](../../api.md). Canonical location: [MenuButton](../../api.md#menubutton).

This object describes the bot's menu button in a private chat. It should be one of

* [MenuButtonCommands](./menubuttoncommands.md)
* [MenuButtonWebApp](./menubuttonwebapp.md)
* [MenuButtonDefault](./menubuttondefault.md)

If a menu button other than [MenuButtonDefault](./menubuttondefault.md) is set for a private chat, then it is applied in the chat. Otherwise the default menu button is applied. By default, the menu button opens the list of bot commands.
