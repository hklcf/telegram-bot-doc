# OwnedGift

> Part of the [Telegram Bot API](../../api.md). Canonical location: [OwnedGift](../../api.md#ownedgift).

This object describes a gift received and owned by a user or a chat. Currently, it can be one of

* [OwnedGiftRegular](./ownedgiftregular.md)
* [OwnedGiftUnique](./ownedgiftunique.md)
