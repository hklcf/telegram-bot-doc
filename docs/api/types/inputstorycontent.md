# InputStoryContent

> Part of the [Telegram Bot API](../../api.md). Canonical location: [InputStoryContent](../../api.md#inputstorycontent).

This object describes the content of a story to post. Currently, it can be one of

* [InputStoryContentPhoto](./inputstorycontentphoto.md)
* [InputStoryContentVideo](./inputstorycontentvideo.md)
