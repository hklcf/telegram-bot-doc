# InputPollMedia

> Part of the [Telegram Bot API](../../api.md). Canonical location: [InputPollMedia](../../api.md#inputpollmedia).

This object represents the content of a poll description or a quiz explanation to be sent. It should be one of

* [InputMediaAnimation](./inputmediaanimation.md)
* [InputMediaAudio](./inputmediaaudio.md)
* [InputMediaDocument](./inputmediadocument.md)
* [InputMediaLivePhoto](./inputmedialivephoto.md)
* [InputMediaLocation](./inputmedialocation.md)
* [InputMediaPhoto](./inputmediaphoto.md)
* [InputMediaVenue](./inputmediavenue.md)
* [InputMediaVideo](./inputmediavideo.md)
