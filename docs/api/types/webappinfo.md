# WebAppInfo

> Part of the [Telegram Bot API](../../api.md). Canonical location: [WebAppInfo](../../api.md#webappinfo).

Describes a [Web App](../../webapps.md).

|Field|Type|Description|
|-----------|
|url|String|An HTTPS URL of a Web App to be opened with additional data as specified in [Initializing Web Apps](../../webapps.md#initializing-mini-apps)|
