# ManagedBotCreated

> Part of the [Telegram Bot API](../../api.md). Canonical location: [ManagedBotCreated](../../api.md#managedbotcreated).

This object contains information about the bot that was created to be managed by the current bot.

|Field|Type|Description|
|-----------|
|bot|[User](./user.md)|Information about the bot. The bot's token can be fetched using the method [getManagedBotToken](../methods/getmanagedbottoken.md).|
