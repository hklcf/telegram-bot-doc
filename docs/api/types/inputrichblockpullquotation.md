# InputRichBlockPullQuotation

> Part of the [Telegram Bot API](../../api.md). Canonical location: [InputRichBlockPullQuotation](../../api.md#inputrichblockpullquotation).

A quotation with centered text, loosely corresponding to the HTML tag `<aside>`.

|Field|Type|Description|
|-----------|
|type|String|Type of the block, always "pullquote"|
|text|[RichText](./richtext.md)|Text of the block|
|credit|[RichText](./richtext.md)|*Optional*. Credit of the block|
