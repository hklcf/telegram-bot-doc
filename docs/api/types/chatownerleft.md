# ChatOwnerLeft

> Part of the [Telegram Bot API](../../api.md). Canonical location: [ChatOwnerLeft](../../api.md#chatownerleft).

Describes a service message about the chat owner leaving the chat.

|Field|Type|Description|
|-----------|
|new_owner|[User](./user.md)|*Optional*. The user who will become the new owner of the chat if the previous owner does not return to the chat|
