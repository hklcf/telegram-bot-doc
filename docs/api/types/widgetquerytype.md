# WidgetQueryType

> Part of the [Telegram Bot API](../../api.md). Canonical location: [WidgetQueryType](../../api.md#widgetquerytype).

This object describes the type of a query from a widget. Currently, it can be one of

* [WidgetQueryTypeData](./widgetquerytypedata.md)
* [WidgetQueryTypeSignData](./widgetquerytypesigndata.md)
* [WidgetQueryTypeSentTransaction](./widgetquerytypesenttransaction.md)
