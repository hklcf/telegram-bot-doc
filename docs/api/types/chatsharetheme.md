# ChatShareTheme

> Part of the [Telegram Bot API](../../api.md). Canonical location: [ChatShareTheme](../../api.md#chatsharetheme).

This object describes the theme of the screen for sharing a link to a user or a chat. Currently, it can be one of

* [ChatShareThemeEmoji](./chatsharethemeemoji.md)
* [ChatShareThemeUniqueGift](./chatsharethemeuniquegift.md)
