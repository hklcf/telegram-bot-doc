# BotCommandScopeDefault

> Part of the [Telegram Bot API](../../api.md). Canonical location: [BotCommandScopeDefault](../../api.md#botcommandscopedefault).

Represents the default [scope](./botcommandscope.md) of bot commands. Default commands are used if no commands with a [narrower scope](../../api.md#determining-list-of-commands) are specified for the user.

|Field|Type|Description|
|-----------|
|type|String|Scope type, must be *default*|
