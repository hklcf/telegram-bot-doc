# InputPollOptionMedia

> Part of the [Telegram Bot API](../../api.md). Canonical location: [InputPollOptionMedia](../../api.md#inputpolloptionmedia).

This object represents the content of a poll option to be sent. It should be one of

* [InputMediaAnimation](./inputmediaanimation.md)
* [InputMediaLink](./inputmedialink.md)
* [InputMediaLivePhoto](./inputmedialivephoto.md)
* [InputMediaLocation](./inputmedialocation.md)
* [InputMediaPhoto](./inputmediaphoto.md)
* [InputMediaSticker](./inputmediasticker.md)
* [InputMediaVenue](./inputmediavenue.md)
* [InputMediaVideo](./inputmediavideo.md)
