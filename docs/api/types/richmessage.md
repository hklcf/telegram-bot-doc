# RichMessage

> Part of the [Telegram Bot API](../../api.md). Canonical location: [RichMessage](../../api.md#richmessage).

Rich formatted message.

|Field|Type|Description|
|-----------|
|blocks|Array of [RichBlock](./richblock.md)|Content of the message|
|is_rtl|Boolean|*Optional*. *True*, if the rich message must be shown right-to-left|
