# SentWebAppMessage

> Part of the [Telegram Bot API](../../api.md). Canonical location: [SentWebAppMessage](../../api.md#sentwebappmessage).

Describes an inline message sent by a [Web App](../../webapps.md) on behalf of a user.

|Field|Type|Description|
|-----------|
|inline_message_id|String|*Optional*. Identifier of the sent inline message. Available only if there is an [inline keyboard](./inlinekeyboardmarkup.md) attached to the message.|
