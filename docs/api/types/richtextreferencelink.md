# RichTextReferenceLink

> Part of the [Telegram Bot API](../../api.md). Canonical location: [RichTextReferenceLink](../../api.md#richtextreferencelink).

A link to a reference.

|Field|Type|Description|
|-----------|
|type|String|Type of the rich text, always "reference_link"|
|text|[RichText](./richtext.md)|The link text|
|reference_name|String|The name of the reference|
