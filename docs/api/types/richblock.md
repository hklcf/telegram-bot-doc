# RichBlock

> Part of the [Telegram Bot API](../../api.md). Canonical location: [RichBlock](../../api.md#richblock).

This object represents a block in a rich formatted message. Currently, it can be any of the following types:

* [RichBlockParagraph](./richblockparagraph.md)
* [RichBlockSectionHeading](./richblocksectionheading.md)
* [RichBlockPreformatted](./richblockpreformatted.md)
* [RichBlockFooter](./richblockfooter.md)
* [RichBlockDivider](./richblockdivider.md)
* [RichBlockMathematicalExpression](./richblockmathematicalexpression.md)
* [RichBlockAnchor](./richblockanchor.md)
* [RichBlockList](./richblocklist.md)
* [RichBlockBlockQuotation](./richblockblockquotation.md)
* [RichBlockExpandableBlockQuotation](./richblockexpandableblockquotation.md)
* [RichBlockPullQuotation](./richblockpullquotation.md)
* [RichBlockCollage](./richblockcollage.md)
* [RichBlockSlideshow](./richblockslideshow.md)
* [RichBlockTable](./richblocktable.md)
* [RichBlockDetails](./richblockdetails.md)
* [RichBlockMap](./richblockmap.md)
* [RichBlockButtons](./richblockbuttons.md)
* [RichBlockAnimation](./richblockanimation.md)
* [RichBlockAudio](./richblockaudio.md)
* [RichBlockDocument](./richblockdocument.md)
* [RichBlockPhoto](./richblockphoto.md)
* [RichBlockVideo](./richblockvideo.md)
* [RichBlockVoiceNote](./richblockvoicenote.md)
* [RichBlockThinking](./richblockthinking.md)
