# EmojiTypeCustomEmoji

> Part of the [Telegram Bot API](../../api.md). Canonical location: [EmojiTypeCustomEmoji](../../api.md#emojitypecustomemoji).

A custom emoji.

|Field|Type|Description|
|-----------|
|type|String|Type of the emoji, always "custom_emoji"|
|custom_emoji_id|String|Identifier of the custom emoji. Use [getCustomEmojiStickers](../methods/getcustomemojistickers.md) to get full information about the sticker.|
