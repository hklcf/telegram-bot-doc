# VideoChatParticipantsInvited

> Part of the [Telegram Bot API](../../api.md). Canonical location: [VideoChatParticipantsInvited](../../api.md#videochatparticipantsinvited).

This object represents a service message about new members invited to a video chat.

|Field|Type|Description|
|-----------|
|users|Array of [User](./user.md)|New members that were invited to the video chat|
