# RichBlockVoiceNote

> Part of the [Telegram Bot API](../../api.md). Canonical location: [RichBlockVoiceNote](../../api.md#richblockvoicenote).

A block with a voice note, corresponding to the HTML tag `<audio>`.

|Field|Type|Description|
|-----------|
|type|String|Type of the block, always "voice_note"|
|voice_note|[Voice](./voice.md)|The voice note|
|caption|[RichBlockCaption](./richblockcaption.md)|*Optional*. Caption of the block|
