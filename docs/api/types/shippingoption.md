# ShippingOption

> Part of the [Telegram Bot API](../../api.md). Canonical location: [ShippingOption](../../api.md#shippingoption).

This object represents one shipping option.

|Field|Type|Description|
|-----------|
|id|String|Shipping option identifier|
|title|String|Option title|
|prices|Array of [LabeledPrice](./labeledprice.md)|List of price portions|
