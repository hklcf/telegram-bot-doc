# InputRichBlock

> Part of the [Telegram Bot API](../../api.md). Canonical location: [InputRichBlock](../../api.md#inputrichblock).

This object represents a block in a rich formatted message to be sent. Currently, it can be any of the following types:

* [InputRichBlockParagraph](./inputrichblockparagraph.md)
* [InputRichBlockSectionHeading](./inputrichblocksectionheading.md)
* [InputRichBlockPreformatted](./inputrichblockpreformatted.md)
* [InputRichBlockFooter](./inputrichblockfooter.md)
* [InputRichBlockDivider](./inputrichblockdivider.md)
* [InputRichBlockMathematicalExpression](./inputrichblockmathematicalexpression.md)
* [InputRichBlockAnchor](./inputrichblockanchor.md)
* [InputRichBlockList](./inputrichblocklist.md)
* [InputRichBlockBlockQuotation](./inputrichblockblockquotation.md)
* [InputRichBlockExpandableBlockQuotation](./inputrichblockexpandableblockquotation.md)
* [InputRichBlockPullQuotation](./inputrichblockpullquotation.md)
* [InputRichBlockCollage](./inputrichblockcollage.md)
* [InputRichBlockSlideshow](./inputrichblockslideshow.md)
* [InputRichBlockTable](./inputrichblocktable.md)
* [InputRichBlockDetails](./inputrichblockdetails.md)
* [InputRichBlockMap](./inputrichblockmap.md)
* [InputRichBlockButtons](./inputrichblockbuttons.md)
* [InputRichBlockAnimation](./inputrichblockanimation.md)
* [InputRichBlockAudio](./inputrichblockaudio.md)
* [InputRichBlockDocument](./inputrichblockdocument.md)
* [InputRichBlockPhoto](./inputrichblockphoto.md)
* [InputRichBlockVideo](./inputrichblockvideo.md)
* [InputRichBlockVoiceNote](./inputrichblockvoicenote.md)
* [InputRichBlockThinking](./inputrichblockthinking.md)
