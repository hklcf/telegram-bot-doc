# InlineQueryResult

> Part of the [Telegram Bot API](../../api.md). Canonical location: [InlineQueryResult](../../api.md#inlinequeryresult).

This object represents one result of an inline query. Telegram clients currently support results of the following 20 types:

* [InlineQueryResultCachedAudio](./inlinequeryresultcachedaudio.md)
* [InlineQueryResultCachedDocument](./inlinequeryresultcacheddocument.md)
* [InlineQueryResultCachedGif](./inlinequeryresultcachedgif.md)
* [InlineQueryResultCachedMpeg4Gif](./inlinequeryresultcachedmpeg4gif.md)
* [InlineQueryResultCachedPhoto](./inlinequeryresultcachedphoto.md)
* [InlineQueryResultCachedSticker](./inlinequeryresultcachedsticker.md)
* [InlineQueryResultCachedVideo](./inlinequeryresultcachedvideo.md)
* [InlineQueryResultCachedVoice](./inlinequeryresultcachedvoice.md)
* [InlineQueryResultArticle](./inlinequeryresultarticle.md)
* [InlineQueryResultAudio](./inlinequeryresultaudio.md)
* [InlineQueryResultContact](./inlinequeryresultcontact.md)
* [InlineQueryResultGame](./inlinequeryresultgame.md)
* [InlineQueryResultDocument](./inlinequeryresultdocument.md)
* [InlineQueryResultGif](./inlinequeryresultgif.md)
* [InlineQueryResultLocation](./inlinequeryresultlocation.md)
* [InlineQueryResultMpeg4Gif](./inlinequeryresultmpeg4gif.md)
* [InlineQueryResultPhoto](./inlinequeryresultphoto.md)
* [InlineQueryResultVenue](./inlinequeryresultvenue.md)
* [InlineQueryResultVideo](./inlinequeryresultvideo.md)
* [InlineQueryResultVoice](./inlinequeryresultvoice.md)

**Note:** All URLs passed in inline query results will be available to end users and therefore must be assumed to be **public**.
